# CANAPhonics · site officiel

Site du groupe CANAPhonics (EP « A Jamais », remasterisé), fait à partir du modèle Riff de SceneVolt.

- `index.html` : la page entière. Les textes, les titres, les liens Spotify / Apple Music, les musiciens et les contacts sont dans le bloc `SETTINGS`, en bas du fichier.
- `img/` : les photos et les pochettes.
- Mise en ligne : Netlify publie automatiquement chaque modification poussée sur la branche `main`.
